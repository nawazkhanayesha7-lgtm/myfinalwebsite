01 / Explore the craft

What is graphic design?

Graphic design is visual communication. It combines images, type, color and layout to share a message clearly and beautifully.

Visual communication

Use visual elements to explain an idea, tell a story or guide someone toward an action.

02 / Design foundations

Know the principles.

Strong designs are not random. These foundations help every element feel intentional and easy to understand.

◉

Contrast

Make important elements stand out using differences in size, color, weight or shape.

▤

Hierarchy

Guide the eye from the most important message to supporting details in the right order.

▦

Alignment

Arrange elements along clear edges or guides to create a tidy, connected layout.

◫

Balance

Distribute visual weight so a composition feels stable, calm or purposefully dynamic.

✳

Repetition

Repeat colors, shapes and styles to create consistency and a recognizable visual system.

↔

Proximity

Place related items near each other so information is easier to scan and understand.

◌

White space

Give content room to breathe. Empty space is an active part of a good composition.

⌁

Consistency

Keep your visual choices connected so the whole design feels like one complete piece.

05 / Color theory

Build a better palette.

Color affects mood, meaning and readability. Start with a small palette and give each color a role.

Quick color guide

Color is a design decision.

RGB is used for screens and digital displays. CMYK is used for most professional print workflows. Check the final output before exporting.

06 / A simple workflow

From blank page to final design.

A repeatable process saves time and helps you make thoughtful creative decisions.

01

Understand

Know the audience, goal, message and where the design will appear.

02

Research

Collect references, explore styles and sketch a few possible directions.

03

Create

Build the layout, choose type and colors, then refine spacing and details.

04

Review & export

Check readability, dimensions and file format before sharing or printing.
